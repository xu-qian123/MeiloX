# 合并上游 1.55.0

日期：2026-10-16。目标是把 `NEORUAA/MeiloX` 发布标签 `1.55.0` 合并到当前分支 `main`；不是合并上游标签之后的 main。

- 上游提交：`b99f2f28d0807acecc98ab8cd6690fd96c65a075`，本地引用 `upstream-1.55.0`。
- 双方共同基点：`1d830d3f9cd11294e2bb977c7d0ba77f0fb8ca29`。
- 合并前将 A—E 批次未提交的优化保存为独立提交 `9c51376`，并建立恢复分支 `codex/backup-before-upstream-1.55.0`。
- 只在本地合并，不推送远端，不安装手机 APK。

## 整合原则

保留上游登录/移动端会话、账号绑定首页缓存、多页首页、相似 FM、音质探测与解码失败恢复、媒体库分类与分页、评论操作、外观和导航设置、歌词快照/对唱/缓存修复以及依赖升级。重叠代码手工整合，避免单纯使用整个本地或上游版本覆盖另一方功能。

保留分支已有的“朝歌”名称与标志、系统字体、AppleMusic 进度条及歌词拖动预览、自定义歌词/来源匹配/偏移/音译、稳定曲目标识、PCM 响度均衡、FFmpeg 解码扩展、离线缓存选择，以及 A—E 的取消传播和异步设置读取。

主要冲突处理：

- CI 继续使用仓库 Wrapper、先执行无发布凭据的验证；release 构建接入上游构建来源/运行次数参数。
- 首页采用上游按账号缓存与多页加载，继续由仓库挂起读取 Android ID，再传给纯请求 DSL。
- 歌词采用上游在发布快照前完成对唱识别和来源选择的流程，同时保留已有 LyricLoadSession、手动搜索代际、来源请求超时、自定义翻译叠加、逐词兜底及音译缓存。
- QQ 缓存保留 QRC 原文，兼容旧缓存中被错误标为 QRC 的 LRC；恢复函数同时保留本地音译和编辑器原文。
- 媒体源继续保证同一数据源 seek 时使用一致的缓存表示，同时接入上游已拒绝缓存过滤与来源追踪，保留本地 FFmpeg 和响度处理链。
- 进度更新隔离到独立子树，保留现有 AppleMusic 进度条和预览回调，不恢复已被替换的两个旧进度条组件。
- 媒体库使用上游分类、账号绑定和分页实现，同时保留本地歌曲播放指示、下拉刷新“喜欢的音乐”，并把列表顺序写入本地 sortOrder。
- 上游统一字体样式和字距设置继续生效，AppFontFamily 保留本分支的系统字体。
- 两侧同名 ResponseHandlerTest 分别保留为本地测试和 UpstreamResponseHandlerTest，不删除取消回归或上游空响应检查。
- 分开命名 HTTP 响应降级判断和解码错误降级判断，防止两侧同名 Int 参数函数冲突；音质回退采用上游的新顺序，本地缓存读取仍支持 legacy higher 表示。
- 跨音质离线缓存回退时，从实际缓存键恢复来源音质，接入上游的实际音质显示/恢复状态，避免把请求音质误作播放音质；已有缓存键及音频字节保持不变，增加对应回归用例。
- Windows 下将 SDK 的 `.dat` 资源标记为二进制，禁止 Git 改写行尾；逐一核验工作区及已构建 APK 中 5 个文件均与发布标签的原始字节一致，没有清理或打印资源内容。

## 构建环境与验证

上游默认 NDK 为 `27.1.12297006`。本机已有 `28.2.13676358`，首次构建自动下载 27.1 速度过慢；核实本轮 Python→cmd→Wrapper→Daemon 父子关系后只停止该轮 Gradle。新增可选 `mei.ndkVersion` 属性，默认仍为上游 27.1，本地验证使用 `-Pmei.ndkVersion=28.2.13676358`，不修改系统默认 JDK 或 SDK 配置。默认 NDK 27.1 的完整验证仍待完成。

JDK 21，组合命令：

```text
gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug :app:assembleDebugAndroidTest -Pmei.ndkVersion=28.2.13676358 --no-daemon --max-workers=4 -Pkotlin.compiler.execution.strategy=in-process --continue --console=plain
```

主代码、原生库、两种调试 APK 均已构建成功。最终合并源码的 101 个 suite、658 个单元用例全部通过，0 失败/错误/跳过；包含两侧原测试，以及新增的 FFmpeg Java 加载接口、缓存音译/编辑原文保留和缓存实际音质回归。最终组合检查耗时 309.91 秒，前后输入哈希一致；总体退出码为 1，原因是 lint 的 102 条发现阻断，并非测试或 APK 构建失败。证据为被忽略的 `upstream-1.55.0-validation.log`、`temp/upstream-1.55.0-result.json`。

进度子树的纯缩进问题已修正。单独 lint 复核及最终组合验证均确认剩余 102 条发现；没有将旧版本的 425 个测试或修复缓存实际音质前的 657 个测试混作最终源码的验证证据。
